Type: grilling
Status: open

## Question

The app opens on the **Collection screen** (title **Solitaire Collection**). Choosing Klondike opens **Klondike start** (**New Game**, **Winning deal**, **Resume**, **Settings**, **About**). An unfinished Game does not start by itself. **Resume** stays on **Klondike start**.

Table chrome **Start**, and **Start** on a win or a loss, leave the table today for the screen where Resume lives.

Where does that **Start** control land, and how does the player get from **Klondike start** back to the **Collection screen**?
