# Can we enroll in Play Console as an individual?

Type: task
Status: open

HITL — the owner must enroll; the agent cannot stand in for identity, payment, or age attestation.

Facts already locked on [What do Apple and Google require to list a free no-account phone game?](https://github.com/jusanherndon/Solitare/issues/5): US$25 one-time registration fee; age 18+; personal accounts created after 13 November 2023 must complete closed testing before production. ([Get started with Play Console](https://support.google.com/googleplay/android-developer/answer/6112435))

## Question

Can the owner enroll in Google Play Console as a personal developer and create a free Game app record named Klondike Solitaire?

## Done when

- Owner has a Play Console developer account (personal vs organization recorded on this ticket).
- A comment records that the US$25 registration succeeded — not passwords, not payment details.
- The Klondike Solitaire app exists in Console as a **game**, **free**, ads declaration **No** (or the ads declaration is listed as a follow-up if Console defers it).
- If Home still shows it: device verification via the Play Console app (account owner, non-rooted Android 10+). Separate from the 12/14 clock; both sit on the personal-account path to public release.
- Closed testing is **not** done on this ticket; that is [Can we run the closed test and apply for production?](issues/11-run-closed-test-apply-production.md).
